## FastUtf8 [#fast-utf8]

A class providing fast UTF-8 encoding and decoding. Reusing an internal buffer keeps allocations low.

```ts import.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8();
```

## LatestOneCacheMap [#latest-one-cache-map]

A simple cache that keeps only the most recent entry. Satisfies `ICacheMap`.

```ts cache.ts
import { LatestOneCacheMap } from "fast-utf8";

const cache = new LatestOneCacheMap(1024);
```

<TypeTable
  type={{
    maxCacheSize: {
      type: "number",
      required: true,
      description: "The maximum number of bytes that can be kept.",
    },
  }}
/>

Values over the limit are not stored, and the older value is kept. Lookups with a non-matching key return `null`.
