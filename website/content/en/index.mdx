## Why choose it [#why]

- Drop-in replacement. Returns the same results as `TextEncoder` and `TextDecoder`.
- Fewer allocations for short strings. Reuses a 1024-byte internal buffer by default.
- Caching helps with repeated boilerplate. Ships with an implementation that keeps the most recent entry.
- Safe to mutate return values. Always copies data at input/output boundaries.

## Quickstart [#quickstart]

```ts basic.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8();

const encoded = utf8.encode("こんにちは"); // 15 bytes
console.log(utf8.decode(encoded)); // こんにちは
console.log(utf8.countBytes("こんにちは")); // 15
```
