title: 厳格モードと検証
description: 不正な入力の扱いを決めるための設定です。
---

既定では寛容に変換し、外部からの入力だけ厳しく扱います。

## 厳格モード [#strict]

`strict` を有効にすると、不正なバイト列の `decode` で例外を投げます。`encode` の結果は常に正しい UTF-8 になるため、設定の影響は `decode` だけです。

```ts strict.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8({ strict: true });

utf8.decode(new Uint8Array([0xff])); // 例外を投げます
```

検証だけを厳しくした複製を作りたいときは `utf8.clone({ strict: true })` を使ってください。詳しくは[設定の引き継ぎ](./clone)を参照してください。

## 検証と BOM の扱い [#validate]

例外を避けたいときは `isValidUtf8` を使ってください。文字列を渡した場合は常に `true` を返します。

```ts valid.ts
const utf8 = new FastUtf8();

console.log(utf8.isValidUtf8(new Uint8Array([0xff]))); // false
```

先頭の BOM は既定で除去されます。残したいときは `new FastUtf8({ ignoreBOM: true })` を指定してください。`TextDecoder` の同名オプションにそのまま渡ります。

## 使い分けの目安 [#guide]

| 場面                     | 設定                              |
| ------------------------ | --------------------------------- |
| 通常の変換               | 既定のまま使います                |
| 外部からの入力を検査する | `strict: true` で `decode` します |
| 例外を避けて調べる       | `isValidUtf8` を使います          |
| 先頭の BOM を残す        | `ignoreBOM: true` を指定します    |
