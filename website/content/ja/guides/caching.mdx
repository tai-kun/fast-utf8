---
title: キャッシュの使い方
description: 繰り返しの変換を速くするための設定です。
---

定型文やラベルなど、同じ文字列を繰り返す場合に有効です。既定で有効になっており、直近の 1 件を保持します。

## 繰り返しの変換 [#defaults]

```ts cache-default.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8(); // caching: true

const first = utf8.encode("hello");
const second = utf8.encode("hello"); // 同じ内容の別物が返ります

first[0] = 0x42; // 返り値を書き換えても保存内容は壊れません
console.log(utf8.encode("hello")[0]); // 0x68 のままです
```

`countBytes` も保存済みの長さをそのまま返します。

## キャッシュの無効化 [#disable]

入力が毎回異なる場合は無効にしてください。余分な複製を作りません。

```ts cache-off.ts
const utf8 = new FastUtf8({ caching: false });
```

## 保存先の変更 [#custom-map]

`cacheMap` に `ICacheMap` を満たす値を渡すと、保存先を差し替えられます。保持量を絞りたいときは `new LatestOneCacheMap(1024)` を渡してください。`maxCacheSize` を超える値は保存せず、結果は正しく返ります。

```ts custom-cache.ts
import { FastUtf8, type ICacheMap } from "fast-utf8";

const store = new Map<string, Uint8Array<ArrayBuffer>>();

const cacheMap: ICacheMap = {
  get: (text) => store.get(text) ?? null,
  set: (text, data) => {
    store.set(text, data);
  },
  clear: () => {
    store.clear();
  },
};

const utf8 = new FastUtf8({ cacheMap });
```

:::note
独自実装が例外を投げても、本処理は止まりません。読み取りの失敗は未保存として扱い、保存の失敗は無視します。
:::

## 注意点 [#notes]

- `encodeInto` はすべて書き切ったときだけ保存します。途中の内容が後の `encode` に混ざることはありません。
- `clone` は保存先を共有します。分けたいときは `cacheMap` を渡してください。詳しくは[設定の引き継ぎ](./clone)を参照してください。
- 保存内容を捨てたいときは `utf8.clearCache()` を呼び出してください。
