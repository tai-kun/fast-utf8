---
title: バッファーの考え方
description: 割り当てを抑えるための内部バッファーの設定です。
---

短い文字列では内部バッファーを使い回し、長い文字列では新しく割り当てます。切り替えは文字数で自動的に決まります。

## 安全な文字数 [#safe-length]

UTF-8 では 1 文字が最大で 3 バイトになります。そのため、次の式を満たす文字数は必ず内部バッファーに収まります。

$$
\text{安全な文字数} = \left\lfloor \frac{\text{allocateSize}}{3} \right\rfloor
$$

既定の 1024 バイトでは 341 文字までが対象です。

## 大きさを変える [#allocate-size]

短い文字列が多い場合は小さく、長い文字列が多い場合は大きくしてください。

```ts allocate.ts
import { FastUtf8 } from "fast-utf8";

// 512 バイトの内部バッファーを使う
const utf8 = new FastUtf8({ allocateSize: 512 });
```

:::note
大きさは動作を変えません。結果の内容は `TextEncoder` と同じです。変わるのは割り当ての回数だけです。
:::

## 外部のバッファーを使う [#unsafe-buffer]

自分で用意した `Uint8Array` を使い回すこともできます。渡した後は外側から変更しないでください。

```ts unsafe.ts
const shared = new Uint8Array(2048);
const utf8 = new FastUtf8({ unsafeBuffer: shared });
```

:::warning[ご注意]
`unsafeBuffer` の内容は内部で上書きされます。ほかの用途と共有しないでください。
:::

## 直接書き込む [#encode-into]

呼び出し側のバッファーへ直接書きたいときは `encodeInto` を使ってください。戻り値の `read` と `written` は標準 API と同じ意味です。

```ts into.ts
const utf8 = new FastUtf8();
const destination = new Uint8Array(16);

const result = utf8.encodeInto("あ", destination);

console.log(result); // { read: 1, written: 3 }
```

## 数えるだけなら [#count-bytes]

バイト列が不要で長さだけが要る場合は `countBytes` を使ってください。短い文字列では内部バッファーで数えるため、結果の複製を作りません。

```ts count.ts
console.log(utf8.countBytes("こんにちは")); // 15
```
