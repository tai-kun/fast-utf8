標準 API と同じ結果を、より少ない割り当てで得られます。まずは既定の設定で動かしてみてください。

<Steps>
  <Step title="インストールする">
    パッケージを追加します。

    ```package-install
    npm i fast-utf8
    ```

  </Step>
  <Step title="インスタンスを作る">
    既定ではキャッシュが有効で、1024 バイトの内部バッファーを使います。

    ```ts app.ts
    import { FastUtf8 } from "fast-utf8";

    const utf8 = new FastUtf8();
    ```

  </Step>
  <Step title="変換してみる">
    `encode` と `decode` は標準 API と同じ内容を返します。

    ```ts app.ts
    const encoded = utf8.encode("こんにちは");
    const text = utf8.decode(encoded);

    console.log(text); // こんにちは
    ```

  </Step>
</Steps>

## よく使う 4 つの操作 [#operations]

| 操作          | 用途                           | 例                        |
| ------------- | ------------------------------ | ------------------------- |
| `encode`      | 文字列をバイト列に変換します   | `utf8.encode("あ")`       |
| `decode`      | バイト列を文字列に戻します     | `utf8.decode(bytes)`      |
| `countBytes`  | 符号化後のバイト数を数えます   | `utf8.countBytes("あ")`   |
| `isValidUtf8` | バイト列が正しいかを判定します | `utf8.isValidUtf8(bytes)` |

```ts usage.ts
const utf8 = new FastUtf8();

utf8.encode("あ"); // Uint8Array(3) [0xe3, 0x81, 0x82]
utf8.countBytes("あ"); // 3
utf8.isValidUtf8(new Uint8Array([0xff])); // false
```

:::note
文字列を `isValidUtf8` に渡した場合は常に `true` を返します。文字列は必ず符号化できるためです。バイト列の正誤を調べたいときに使ってください。
:::
