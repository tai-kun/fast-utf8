`FastUtf8` を中心に、`LatestOneCacheMap` と関連する型をまとめています。まずは[はじめに](../getting-started)で基本操作を試し、詳しい使い方は[ガイド](../guides)で確認してください。

## FastUtf8 [#fast-utf8]

高速な UTF-8 のエンコードとデコードを提供するクラスです。内部バッファーの使い回しによって割り当てを抑えます。

```ts import.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8();
```

### プロパティー [#properties]

## LatestOneCacheMap [#latest-one-cache-map]

直近の 1 件だけを保持する簡易なキャッシュです。`ICacheMap` を満たします。

```ts cache.ts
import { LatestOneCacheMap } from "fast-utf8";

const cache = new LatestOneCacheMap(1024);
```

<TypeTable
  type={{
    maxCacheSize: {
      type: "number",
      required: true,
      description: "保持できる最大のバイト数です。",
    },
  }}
/>

上限を超える値は保存せず、古い値を残します。一致しないキーの取得では `null` を返します。
