`FastUtf8` は `TextEncoder` と `TextDecoder` を使い回し、短い文字列では内部バッファーを再利用します。同じ文字列を繰り返し扱う用途では、結果のキャッシュによって割り当てをさらに抑えられます。

## 選ぶ理由 [#why]

- 標準 API と同じ結果を返します。`TextEncoder` と `TextDecoder` を薄く包んでいるだけです。
- 短い文字列では割り当てを抑えます。既定で 1024 バイトの内部バッファーを使い回します。
- 繰り返しの変換ではキャッシュが効きます。直近の 1 件を保持する実装を同梱しています。
- 返り値の変更が内部状態を壊しません。入出力の境界では必ず複製を作ります。

## すぐに試す [#quickstart]

```ts basic.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8();

const encoded = utf8.encode("こんにちは");
console.log(encoded.length); // 15
console.log(utf8.decode(encoded)); // こんにちは
console.log(utf8.countBytes("こんにちは")); // 15
console.log(utf8.isValidUtf8(encoded)); // true
```
