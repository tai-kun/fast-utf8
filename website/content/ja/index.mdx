## 選ぶ理由 [#why]

- 置き換えるだけで動きます。`TextEncoder` と `TextDecoder` と同じ結果を返します。
- 短い文字列では割り当てを抑えます。既定で 1024 バイトの内部バッファーを使い回します。
- 定型文の再変換ではキャッシュが効きます。直近の 1 件を保持する実装を同梱しています。
- 返り値を書き換えても壊れません。入出力の境界では必ず複製を作ります。

## すぐに試す [#quickstart]

```ts basic.ts
import { FastUtf8 } from "fast-utf8";

const utf8 = new FastUtf8();

const encoded = utf8.encode("こんにちは"); // 15 バイト
console.log(utf8.decode(encoded)); // こんにちは
console.log(utf8.countBytes("こんにちは")); // 15
```
